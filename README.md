# Hanming Ye — personal website

A small, static site for GitHub Pages. The site lives in `index.html` and `styles.css`; no build step is needed.

## Updating it

- Edit the text and links in `index.html` to change the bio, publications, startup work, or contact details.
- Edit `styles.css` to change the visual style.
- Once published from the repository's `main` branch, changes pushed to `main` will appear at `https://dozenducc.github.io/`.
